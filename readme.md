# Aureum | Backend

Backend system for a multi-tenant business management platform (SaaS).

## Tech Stack
- Python
- Django
- PostgreSQL
- Django REST Framework

## Features (in progress)
- Multi-tenant architecture
- Organization-based data isolation
- User authentication and role management
- Document management
- Case / workflow management

## Project Structure
The system is designed as a scalable SaaS platform, allowing different organizations to manage their operations while maintaining secure data separation between tenants.
